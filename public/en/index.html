Subtitle Forge AI · English guide

Convert audio and video to text, then edit subtitles online

Subtitle Forge AI is a browser-based transcription and subtitle editing tool. Extract audio from a video, transcribe it using a supported speech service, correct the text and timestamps, and export a subtitle file for your content.

Open the subtitle editor

The main tool offers an English interface. Select EN if your browser opens it in Arabic.

Available subtitle and transcription features

  • Import common audio and video files and extract audio in the browser.
  • Transcribe speech with a supported provider such as Groq, Deepgram, AssemblyAI or Gladia using your own API key.
  • Edit subtitle text and timing and preview content before export.
  • Export subtitle and transcript files as SRT, VTT, ASS, TXT or JSON.
  • Record audio in your browser and save work locally when supported by the browser.

How to transcribe and create subtitles

  1. Open the editor and upload an audio or video file.
  2. Select a supported transcription provider and provide its API key.
  3. Run transcription, review the result and adjust text or timing as needed.
  4. Choose the export format for your subtitles or transcript.

Read the full usage guide or learn how the project works.

Privacy and service requirements

Video/audio extraction and editing occur locally in the browser. Transcription with a cloud provider sends the audio needed for recognition directly to that selected third-party provider. Each provider has its own eligibility, pricing, free-tier rules and privacy terms.

You do not need an account with Subtitle Forge AI itself, but cloud transcription requires an account and API key with the provider you choose. Check the privacy policy before submitting any sensitive audio.
