# SubtitleForge — تقدّم التنفيذ

## الجلسات المنفَّذة حتى الآن

### ✅ Session 1 — الأساس والهيكلة
React + TypeScript + Vite + Tailwind، هيكل المجلدات، نظام المظهر
(فاتح/غامق/حسب النظام)، تصميم عام RTL.

### ✅ Session 2 — الصفحة الرئيسية والرفع
- أزرار "رفع فيديو" / "رفع صوت" تفتح منتقي ملفات حقيقي (يعمل من متصفح
  الهاتف عبر Choose File، ومن الكمبيوتر بنفس الطريقة).
- منطقة Drag & Drop كاملة على الكمبيوتر.
- تحقق فعلي من الملف قبل قبوله: صيغة غير مدعومة → خطأ واضح مع نص بديل،
  ملف فارغ → خطأ، ملف كبير جدًا (>1.5GB) → تحذير غير مانع (المستخدم يقرر).
- أزرار "تسجيل صوت" / "فتح مشروع" / "استيراد ترجمة" ظاهرة لكن معطّلة
  بوضوح (Coming Soon) — لا تُعرض كأنها تعمل وهي لا تعمل.
- بعد قبول الملف: ملخص (الاسم، النوع، الحجم) وتوضيح صريح أن خطوات
  المعالجة الفعلية (استخراج الصوت، التفريغ) تُضاف في جلسات لاحقة.

### ✅ Session 6 — نموذج البيانات والتوقيتات
- `src/models/subtitle.ts`: نموذج Cue/Word/Track الموحّد الذي تعتمد عليه
  كل الصيغ.
- `src/subtitles/timestamps.ts`: تحويل ثوانٍ ↔ SRT/VTT time، مع تحقق من
  التنسيق. مُختبَر يدويًا على حالات حدّية (0، 59.999، تقريب .9995 عند حدود
  الدقيقة/الساعة).

### ✅ Session 7 — Subtitle Segmentation Engine
- `src/subtitles/segmentation.ts`: يجمّع كلمات (بتوقيتاتها) إلى Cues حسب
  أقصى أحرف/أسطر ومدة قصوى، مع تفضيل القطع عند علامات نهاية الجملة
  (. ! ؟ ? ، …)، ثم تمريرة ثانية (`enforceMinDurationAndGap`) تضمن حدًا
  أدنى للمدة وفاصلًا أدنى بين الأسطر دون التعدي على السطر التالي.
- لا يقسم كلمة أبدًا (الوحدة الأساسية دائمًا كلمة كاملة).
- مُختبَر يدويًا: جملتين متتاليتين، كلمة واحدة طويلة جدًا زمنيًا، قائمة فاضية.

### ✅ Session 11 (المصادر الأساسية) — Export Engine
- `src/export/{srt,vtt,txt,json}Exporter.ts` + `src/export/index.ts`
  (`ExportEngine` موحّد + `downloadExport` للتنزيل المباشر من المتصفح).
- الصيغ المُنفَّذة الآن: **SRT, VTT, TXT, JSON** (كافية لـ MVP).
- **ASS/SSA/TTML مؤجَّلة عمدًا**: تحتاج نظام Styles/Settings غير مبني
  بعد، وتخمين بنيتها الآن بدون ذلك النظام سيُنتج كودًا يحتاج إعادة كتابة.
- اسم الملف يتبع نمط `video.ar.srt` كما في المواصفة.
- مُختبَر يدويًا: مخرجات SRT وVTT فعلية على نص عربي.

### ⚠️ Session 3 — Media Engine (FFmpeg WebAssembly) — منفَّذة لكن غير مُختبَرة فعليًا
- `src/media/loadFFmpeg.ts`: تحميل كسول (Lazy) لنواة FFmpeg مرة واحدة فقط،
  من نفس أصل الموقع (`/ffmpeg/*`) لا من CDN خارجي.
- `scripts/copy-ffmpeg-core.mjs` + `postinstall` في package.json: ينسخ
  ملفات النواة (`ffmpeg-core.js` / `.wasm`) من `node_modules/@ffmpeg/core`
  إلى `public/ffmpeg/` تلقائيًا بعد `npm install`.
- `src/media/MediaEngine.ts`: `extractAudio()` يحوّل أي فيديو/صوت إلى WAV
  أحادي القناة 16kHz (التنسيق المفضَّل لمحركات STT). `readMetadata()` و
  `createPreview()` عمدًا **لا يستخدمان FFmpeg** — المتصفح نفسه يعطي المدة
  والأبعاد عبر `<video>`/`<audio>` مباشرة، فاستدعاء FFmpeg (تحميل ~30 ميجا)
  لهذا وحده تبذير.
- قرار مرتبط: أزلت رؤوس COOP/COEP من `vite.config.ts` (كانت من Session 1)
  لأننا نستخدم نواة FFmpeg **أحادية الخيط** التي لا تحتاجها، وتفعيلها كان
  سيكسر تحميل خطوط Google Fonts.
- ربطتها بصفحة الرفع: زر "استخراج الصوت" الآن يعمل فعليًا ويعرض مشغّل صوت
  ورابط تنزيل للنتيجة.

**تنبيه مهم بخصوص هذه الجلسة تحديدًا:** لم أستطع تشغيل `npm install` أو
فتح متصفح فعلي هنا (بيئتي بدون إنترنت)، فكل هذا الكود **لم يُختبَر
بالتشغيل الفعلي** — فقط بمراجعة يدوية دقيقة لواجهة مكتبة `@ffmpeg/ffmpeg`
الإصدار 0.12. راجع قسم "أول تشغيل" بالأسفل — هناك احتمال حقيقي لحاجة تعديل
بسيط (خصوصًا في `MediaEngine.ts`) عند أول تشغيل فعلي على جهازك.

3، 4/5 اكتملتا (بالتحفظ أعلاه على 3). الجلسات 8، 9، 10، 12–16 لم تُنفَّذ

1. **Session 4/5** — Speech Engine (تفريغ صوتي فعلي) + اكتشاف اللغة — تحتاج اختيار مكتبة Whisper wasm وتثبيتها فعليًا، الأصح تنفيذها وأنت متصل بالإنترنت لتُختبر فور الكتابة.
2. **Session 8/9** — محرر الترجمة الكامل + معاينة الفيديو (له بيانات حقيقية الآن).
3. **Session 10** — استيراد/تحويل صيغ الترجمة.
4. **Session 12/13** — نظام المشاريع (IndexedDB) + التسجيل الصوتي المباشر.
5. **Session 14–16** — دعم اللهجات/Accessibility، إدارة العمليات، الإعدادات الكاملة + PWA.

## التشغيل محليًا

```bash
npm install
npm run dev
```

### أول تشغيل — تحقّق من استخراج الصوت تحديدًا

1. بعد `npm install`، تأكد أن `public/ffmpeg/ffmpeg-core.js` و
   `ffmpeg-core.wasm` تكوّنا فعليًا (رسالة `[copy-ffmpeg-core] نُسخ: ...`
   تظهر في الطرفية). إن لم تظهر، شغّل يدويًا:
   `node scripts/copy-ffmpeg-core.mjs`
2. ارفع أي فيديو قصير واضغط "استخراج الصوت من الفيديو".
3. افتح Console المتصفح أثناء أول تشغيل — إن ظهر خطأ متعلق بـ
   `ffmpeg.load` أو 404 على `/ffmpeg/ffmpeg-core.wasm`، غالبًا مسار النواة
   في `CORE_BASE_PATH` (داخل `src/media/loadFFmpeg.ts`) يحتاج تعديلًا
   بسيطًا ليطابق مكان الملفات الفعلي عندك.
